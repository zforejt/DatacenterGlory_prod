# Datacenter Glory

An idle game: build AI datacenters from a Prague garage to a Dyson sphere.

**Play:** https://zforejt.github.io/DatacenterGlory_prod/

This is a test build. The game is saved in your browser only. To move it to another browser, use Menu → Settings → Backup code.

On a phone you can add it to the home screen (Safari: Share → Add to Home Screen). It then also works offline.
